## 🚀 立即开始使用

### 1. 登录认证

```swift
// 在LoginView中使用
Task {
    let result = await AuthManager.shared.loginWithUsername(
        phoneNumber,
        password: password
    )
    switch result {
    case .success(let user):
        print("登录成功: \(user.username)")
    case .failure(let error):
        print("错误: \(error)")
    }
}
```

### 2. 获取容器列表

```swift
// 在ContainerListView中使用
Task {
    do {
        let containers = try await ContainerAPIService.shared.getContainers()
        // 更新UI
        await MainActor.run {
            self.containers = containers.map { Container.from(apiContainer: $0) }
        }
    } catch {
        print("获取失败: \(error.localizedDescription)")
    }
}
```

### 3. 上传图片

```swift
// 在需要上传图片的地方
Task {
    do {
        let imageUrl = try await FileUploadService.shared.processAndUploadImage(
            selectedImage,
            type: .image
        )
        print("上传成功: \(imageUrl)")
    } catch {
        print("上传失败: \(error.localizedDescription)")
    }
}
```

// 开发环境（默认）

// 生产环境
static let prodBaseURL = "https://api.epicfish.cn/thingz/api/v1"

### 修改API地址

如果后端服务器地址改变，只需要修改 `APIConfig.devBaseURL` 或 `APIConfig.prodBaseURL`。

## 💡 使用建议

### 1. 数据同步策略

建议在以下时机从API同步数据：

- **应用启动时** - 加载用户数据、容器列表
- **用户登录后** - 刷新所有数据
- **下拉刷新时** - 更新列表数据
- **操作完成后** - 刷新相关数据

### 2. 错误处理

所有API调用都应该包含错误处理：

```swift
do {
    let data = try await APIService.request(...)
    // 处理成功
} catch APIError.unauthorized {
    // 跳转到登录页面
} catch APIError.networkError(let error) {
    // 显示网络错误提示
} catch {
    // 显示通用错误提示
}
```

### 3. Loading状态

在进行网络请求时显示Loading状态：

```swift
@State private var isLoading = false

func loadData() async {
    isLoading = true
    defer { isLoading = false }

    do {
        let data = try await APIService.request(...)
        // 更新UI
    } catch {
        // 错误处理
    }
}
```

### 4. 图片上传优化

上传图片前建议进行压缩：

```swift
// 使用processAndUploadImage自动处理
let url = try await FileUploadService.shared.processAndUploadImage(
    image,
    maxSize: CGSize(width: 1024, height: 1024),  // 最大尺寸
    maxSizeKB: 500,                               // 最大500KB
    type: .image
)
```

## ⚠️ 注意事项

1. **网络环境**
   - 确保手机/模拟器可以访问 `192.168.3.118:8080`
   - 如果访问不了，检查网络配置或修改API地址

2. **Token管理**
   - Token存储在 `UserDefaults` 中
   - 退出登录时会清除Token
   - Token过期需要重新登录

3. **数据模型**
   - API返回的数据结构与本地模型可能不完全一致
   - 需要进行转换（已提供转换方法）

4. **异步操作**
   - 所有API调用都是异步的
   - UI更新需要在 `MainActor` 中执行

## 🐛 常见问题

### Q1: API请求返回401错误
A: Token过期或无效，需要重新登录

### Q2: 无法连接到服务器
A: 检查API地址配置和网络连接

### Q3: 图片上传失败
A: 检查图片大小，建议先压缩再上传

### Q4: 数据不同步
A: 调用API后需要手动刷新本地数据
